# Parity fixtures

`fusejs-parity.json` is generated by running the real Fuse.js over a set of collections, options and
queries, and recording the results (order, `refIndex`, score and match indices). The Swift test
suite replays every case and requires identical output.

To regenerate (requires Node):

```sh
cd Tests/FuseTests/Fixtures
npm install fuse.js@7
node generate.mjs fusejs-parity.json
```
